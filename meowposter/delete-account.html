Suppression des données

Meowposter — Le jeu de l’imposteur… avec des chats !

Pas de compte Meowposter

Meowposter ne propose pas de création de compte utilisateur. Cartographe ne possède donc pas de compte Meowposter à supprimer pour vous.

Supprimer les données enregistrées sur votre appareil

Les données nécessaires au jeu (par exemple les noms ou pseudonymes saisis, les réglages et les éventuelles données de partie) sont conservées localement sur votre appareil.

  • Sur Android : ouvrez les Paramètres de votre téléphone, puis Applications → Meowposter → Stockage → Effacer les données. Les intitulés peuvent varier selon le fabricant.
  • Vous pouvez également désinstaller Meowposter. Selon le type de données et la version d’Android, certaines données locales peuvent être supprimées lors de la désinstallation.

Achats intégrés

La suppression des données locales ou la désinstallation de l’application n’annule pas automatiquement un abonnement éventuel. Si Meowposter propose un abonnement, vous pouvez le gérer ou l’annuler depuis la rubrique Paiements et abonnements de Google Play.

Données traitées par des prestataires tiers

Les données éventuellement traitées par Google Play ou par le prestataire publicitaire ne sont pas stockées dans les données locales de Meowposter. Pour toute demande les concernant, veuillez consulter les outils de confidentialité et les politiques des prestataires concernés.
